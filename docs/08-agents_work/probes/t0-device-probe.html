Q4

What does the photo picker actually hand over?

Architecture §5.2: whether iOS transcodes HEIC→JPEG depends on the picker path and the device settings, so it must be measured, not assumed. The reported MIME type is not trusted — the first bytes of every file are read and the real container is identified.

NOT RUN

Use a real camera-roll photo — ideally one taken on this phone, outdoors, with Location Services on. The first two are required; the last two isolate whether the accept attribute is what triggers the transcode.
